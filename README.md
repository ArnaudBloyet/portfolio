## ⚙️ Installation

Cloner le projet :

```bash
git clone https://github.com/ArnaudBloyet/portfolio-arnaud.git
```

Installer les dépendances :

```bash
npm install
```

Lancer le serveur de développement :

```bash
npm run dev
```

Créer la version de production :

```bash
npm run build
```
